FX6 — Profondeur de champ

Installation
1. Envoie tout le contenu de ce dossier sur ton hébergement web.
2. Ouvre l'adresse en HTTPS dans Safari sur iPhone.
3. Partager → Sur l'écran d'accueil.
4. L'application fonctionne ensuite comme une mini-app et peut fonctionner hors connexion après la première ouverture.

Calcul
- Préréglage Sony FX6 / plein format.
- Cercle de confusion utilisé : 0,030 mm.
- Formule classique de profondeur de champ via l'hyperfocale.
- Le champ "Diaph" accepte une valeur f/ ou T. Un T-stop donne une approximation car la profondeur de champ dépend théoriquement du f-number.
